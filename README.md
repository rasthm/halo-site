# Halo Automations website

The website for Halo Automations, a small studio that builds websites, web apps, automations and AI agents for growing businesses.

Built with Vite, React 19, GSAP, Lenis and Three.js. Every page is pre-rendered to static HTML and served from a Cloudflare Worker.

## Run it

```bash
npm install
npm run dev        # http://localhost:3020
npm run build      # static build + pre-render into dist/
npm run deploy     # type-check, build and deploy with Wrangler
```

## Branches

- `main`: the main branch.
- `redesign`: the approved motion redesign.
- `neon-wip`: an unapproved experiment, kept for reference.
